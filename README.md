# 🏥 Healthcare Analysis Dashboard

## 📌 Project Overview

The **Healthcare Analysis Dashboard** is an interactive data visualization project developed using **Microsoft Power BI**.

The dashboard provides meaningful insights into healthcare data by analyzing patient information, doctors, healthcare outcomes, and other important performance indicators.

The main goal of this project is to transform raw healthcare data into an interactive and easy-to-understand dashboard that supports **data-driven decision-making**.

---

## 🎯 Project Objective

The objectives of this project are:

* Analyze healthcare and patient-related data.
* Track important healthcare KPIs.
* Analyze doctor and patient information.
* Understand healthcare outcomes and trends.
* Create interactive visualizations for better decision-making.
* Provide an easy-to-use dashboard for exploring healthcare data.

1. Download the `Healthcare_Dashboard.pbix` file.
2. Open it using **Microsoft Power BI Desktop**.
3. Refresh the data if the source dataset is available.
4. Use the available slicers and filters.
5. Interact with the charts and KPIs to explore the data.
